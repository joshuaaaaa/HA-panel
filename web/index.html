Typy stránek

TypPopis
HodinyMalé nebo velké číslice, pruh dní v týdnu, volitelně ikona a efekt v pozadí.
DatumDatum s automatickou ikonou kalendáře (dnešní den).

Každá stránka může mít šablony pro barvu, ikonu, viditelnost (stránka se zobrazí jen když vrací true) a průběh (0–100 → pruh dole). Stisk prostředního tlačítka může přepnout entitu nebo zavolat službu.

MQTT

Základní topic: hapanel/xxxxxx. Při zapnutém auto-discovery se v HA objeví zařízení s entitami: světlo (zap/vyp, jas, barva, efekty), výběr stránky, přepínače, tlačítka, notify, senzory.

TopicPayload
…/notifyText nebo JSON {"text":"Ahoj","icon":"bell","color":"#ff0000","duration":5,"repeat":2,"rainbow":true,"hold":false,"wakeup":true,"progress":40,"stack":true}
…/custom/<název>Dynamická stránka {"text":"22°","icon":"thermometer","color":"orange","progress":50,"duration":6,"lifetime":600}, prázdný payload = smazat
…/indicator1 (2, 3){"color":"#ff0000","blink":500,"lifetime":60} nebo red, prázdné = vypnout
…/cmdnext, prev, select, dismiss, restart
…/page/setNázev stránky
…/powerON / OFF / TOGGLE
…/brightness/set1–255

…/sensor(stav) RSSI, uptime, proud, světlo…

Příklady pro Home Assistant

Notifikace z automatizace (MQTT):

action: mqtt.publish
data:
  topic: hapanel/xxxxxx/notify
  payload: >
    {"text": "Pračka dokončila", "icon": "washer", "color": "#00ff00", "repeat": 2, "wakeup": true}

Notifikace přes entitu notify (auto-discovery):

action: notify.send_message
target:
  entity_id: notify.hapanel_notifikace
data:
  message: "Někdo zvoní!"

Bez MQTT – REST příkaz (configuration.yaml):

rest_command:
  hapanel_notify:
    url: "http://IP/api/notify"
    method: POST
    content_type: "application/json"
    payload: '{"text": "{{ text }}", "icon": "{{ icon | default("bell") }}"}'

Užitečné šablony:

{{ states('sensor.venku_teplota') | float | round(1) }}°
{{ states('weather.forecast_home') }}                       ← jako šablona ikony (sunny, rainy…)
{{ '#ff4000' if states('sensor.spotreba')|float > 3000 else '#ffffff' }}   ← barva
{{ is_state('binary_sensor.pracka', 'on') }}                 ← viditelnost
{{ state_attr('sensor.telefon', 'battery_level') }}          ← průběh 0–100
{{ (states('sensor.fve_vykon')|float / 10000 * 100) | int }}  ← průběh výkonu FVE
